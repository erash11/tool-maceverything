# Handoff 2026-10-16: MacEverything v0.1 build

## What and why
Eric wanted a Mac equivalent of voidtools Everything (instant filename search). Decided not to
reverse engineer the Windows binary: its speed comes from the NTFS MFT and USN journal, which
macOS lacks, and voidtools documents the design. Built a native Swift app instead. Design doc:
https://claude.ai/code/artifact/2dfce39a-ac50-4398-ac64-0f0b77dcef9c

## Decisions and reasoning
- In-memory index of fixed-size records with names in shared byte pools; search scans records in
  memory order across all cores with a flat compiled query (no per-record reference counting,
  which made the first version 430 ms per query).
- `getattrlistbulk()` folder walk for the first scan. `searchfs()` was built and measured (#6):
  about 10% faster but reads whole volumes and would need firmlink mapping for `/`, so the walk
  stays the default; `ev --bench-searchfs` remains as a diagnostic.
- FSEvents for live updates, saving only event ids whose changes are applied; per-device streams
  for `/Volumes` roots so cursors survive use on another Mac.
- Unix socket (JSON lines) instead of XPC between clients and daemon: no launchd Mach service
  registration and easy to test.
- Stable signing (#7) via a free self-signed certificate so Full Disk Access survives rebuilds;
  Developer ID only needed to distribute.
- Reviews: Codex via a review-only PR (now closed, #10) until its usage limit; Sonnet subagents
  afterwards. Every finding was verified and fixed with a test.
